# Village Fun

A scroll-driven photographic tour of a village day: gate, mud lane, fields, market, games, river and a bonfire night.

Open `index.html` through any static web server (for example `python3 -m http.server`).

## Credits

All photographs are real photos from Wikimedia Commons, used under the licence shown for each one in `photos/credits.json`
and in the "Photo credits" section at the bottom of the page. Most are CC BY or CC BY-SA, so attribution and share-alike apply to the photos.
The page code is original; three.js (MIT) is bundled in `lib/`.
